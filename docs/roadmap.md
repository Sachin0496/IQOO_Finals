## Where things are

- Kannada evaluation data: `data/kannada-lab` (local, gitignored); embeddings `data/kannada-emb.npz`.
- Encoder tools: `encoder/mouna_encoder` (`aihub.py` for device jobs; report also written to `deck/data/device-report.json`).
- Deck reads `deck/data/*.json`; rebuild with `cd deck && node build.js && pwsh export_pdf.ps1`.
- Voice render env: `~/.cache/mouna-tts` (short path; the workspace path is too long for Windows DLL loading).
